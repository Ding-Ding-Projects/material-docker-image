# Polish pass at the minimum window size (November 2026)

Design reference for small-window fixes found in captures of the built application at 960 x 720. It is a design record, not proof of implemented behaviour.

- `ImagesCompact.dc.html`: Images at 960 x 720. The selection bar takes the place of the column header while rows are selected, Prune dangling moves into the filter row, the stacked detail becomes a one-line summary (name, ID, size, Run, Inspect, Show details) that expands on request, and secondary header actions fold into More so Pull image stays the single primary action.

The board uses the same subset Material Symbols fonts as `design/workspace-redesign-2026-11/assets/`. In the hosted canvas they are uploaded assets referenced as `/_blob/da32239ae16ef615cdf1f5a3d3c58976` (outline) and `/_blob/6a239dbed13386432890e438260cd981` (filled). Example image names and sizes are illustrative.
