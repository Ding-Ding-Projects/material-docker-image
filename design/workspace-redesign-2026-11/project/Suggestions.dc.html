sharingcache mount option

How builds that run at the same time share this cache. locked makes a second writer wait, which apt and dpkg need; shared lets them write together; private gives each its own copy.

Example
RUN --mount=type=cache,target=/var/cache/apt,sharing=locked \
    apt-get update && apt-get install -y curl
Values: locked · shared (default) · private
